# UDP Server for LeoIoT ecosystem

This library provides a simple, asynchronous UDP server implementation for the LeoIoT ecosystem.

## Dependencies

This library depends on `lib_utils`, `lib_appfw`, `lib_multitasking`, and `lib_net`.
